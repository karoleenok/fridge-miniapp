# Фридж: сервер

Мини-апп, API и бот в одном процессе Node 22, без сторонних пакетов. База в одном файле SQLite (встроенный `node:sqlite`).

## Установка на сервер (Ubuntu 24.04, рядом с другими ботами)

В консоли сервера, от root, одной строкой:

```
curl --fail --silent --show-error --location --proto-default https -o /tmp/fi.sh raw.githubusercontent.com/karoleenok/fridge-miniapp/main/server/deploy/install.sh; bash /tmp/fi.sh
```

Скрипт предложит мост дизайн-бота и адрес, а в конце покажет ссылку `…/claim` и одноразовый код. Токен из @BotFather вставляется на этой странице в обычном браузере (в консоли VNC копирование не работает). Страница проверяет токен через Telegram, сохраняет его в `/var/lib/fridge-bot/bot-token` (права 600, читает только служба) и исчезает. Код живёт час, после 10 неверных попыток страница закрывается; новый код: `bash /opt/fridge-bot/server/deploy/claim.sh`.

Что ставится: папка `/opt/fridge-bot`, пользователь `fridge`, служба `fridge-bot` на `127.0.0.1:8081`, база `/var/lib/fridge-bot/fridge.db`, ежедневная копия базы в `/var/lib/fridge-bot/backup` (14 штук). В `/etc/caddy/Caddyfile` дописывается блок между `# fridge-bot begin/end`, остальное не трогается.

| Команда | Что делает |
|---|---|
| `bash /opt/fridge-bot/server/deploy/update.sh` | обновить код и перезапустить |
| `bash /opt/fridge-bot/server/deploy/status.sh` | служба, очередь сообщений, лог |
| `bash /opt/fridge-bot/server/deploy/switch.sh` | переключить кнопку «Холодильник» на сервер |

## Как устроено

- **Связь с Telegram** через мосты (как у дизайн-бота: несколько адресов через запятую, при сбое берётся следующий) в режиме polling. Все сообщения идут через очередь: если Telegram не ответил, повтор через 20 с, 1, 2, 5, 10, 20, 30 минут, в течение суток.
- **Вход в мини-апп**: подпись `initData` проверяется на сервере (HMAC от токена), старше суток не принимается.
- **Согласие**: до нажатия «Согласен(на)» в боте или в мини-аппе сервер ничего о человеке не хранит.
- **Приглашения**: ссылка `t.me/<бот>?start=inv_…`, одна на холодильник, 24 часа, одноразовая. Вход через бота заодно разрешает боту писать человеку.
- **Просьбы купить**: только участникам своего холодильника, не больше 20 в час. В сообщении кнопка «Куплено», автору приходит ответ.
- **Напоминания**: раз в день в выбранное время (Москва), только если есть что-то со сроком в ближайшие N дней.
- **Удаление данных**: `/delete_me` в боте. `/stop` — не присылать сообщения.

## Проверки

```
npm test       # 37 проверок API, бота и мостов с поддельным Telegram
npm run e2e    # 12 сквозных проверок в браузере (нужен playwright)
node test/claim.js  # 12 проверок одноразовой страницы токена
```

## Перед публичным запуском

- Данные оператора для `/policy` вписываются в `/etc/fridge-bot.env` (`OWNER_INFO`, `CONTACT`), потом `systemctl restart fridge-bot`.
- Текст на `/policy` — черновик. Его должен проверить юрист, и нужно уведомление в Роскомнадзор как оператора персональных данных.
- Шрифт Onest грузится с Google Fonts. Лучше положить его на свой сервер.
